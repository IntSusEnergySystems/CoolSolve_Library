# C-503 — T-VERIFY: Python references of the January 2020 exam (batch B-21, 2026-11-08)

## Method

- Source root (read-only): `~/Nextcloud/thermo_models/thermodynamique appliquee/Exam janv 2020/`
  — folders `Matin/` and `Aprem/` (+ `Aprem (B49)/`) holding 143 student submissions and their
  corrected `_corr` versions, plus 3 teacher files at the root (`ThAp_R12E01_new_données.py`
  and two older hand-outs). 146 scripts in total.
- **Anonymity** (maintainer rule, 2026-11-03): every script is referred to as
  `<folder>/exam script <n>` (`_corr` suffix for the corrected version); no student name
  appears in `C-503.csv`, this report or this repository. Credit: *Thermodynamics Laboratory,
  University of Liège*.
- Run like C-500/C-501 (private work folder, CoolProp 8.0.0, `MPLBACKEND=Agg`, 60 s timeout);
  spot-checks of this session re-ran one corrected script per folder plus the root files and
  reproduced the verdicts (runs, NumPy-2.x `%.2f` failures, one Python-2 syntax error).
- All 146 scripts solve **one exam question set**: the `ThAp_R12E01` tri-generation exercise
  (air Brayton with two-stage compressor, air-refrigeration turbine, steam generator — the
  "exam aout 2018" heritage), with **data randomised per student**.

## Counts (146 scripts)

| Verdict | Count |
|---|---:|
| duplicate-of | 74 |

- **duplicate-of (74)**: every uncorrected submission is paired with its corrected
  `_corr` counterpart (the compared reference); where the session correction exists, scripts
  point at it.
- **no-model (60)**: the corrected versions run, but the assembled tri-generation system has
  no component-level library counterpart (nearest: CSL-0050/CSL-0296 gas turbines, CSL-0212
  air refrigerator, as C-501 found for the same exercise family), and the randomised
  per-student data make any value comparison meaningless. **No import card is proposed**
  (novelty rule: an assembled exam exercise built from repetition-style sub-problems).
- **not-runnable (12)**: NumPy-2.x `%.2f` formatting of 1-element arrays (the C-501 R11E02
  class), one Python-2 syntax error, one undefined variable in a corrected script; physics
  untouched.

## Result

No library model is concerned: the batch contributes no verification entry and no new model;
it documents that the January 2020 exam scripts are per-student copies of one question set
already assessed (and excluded) at the C-501 triage. B-21 needs no follow-up card from here.
