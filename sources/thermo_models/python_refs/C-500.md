# C-500 — T-VERIFY: independent Python references of the course *Thermodynamique appliquée* (batch B-21, 2026-11-08)

## Method

- Source root (read-only): `~/Nextcloud/thermo_models/thermodynamique appliquee/` — folders
  `2022-2023/` (78 teacher solution scripts, author "BJD" = Stéphane Bertagnolio, series
  R01–R11 with `old/`, `v-1/` and `New folder/` copies) and `Aout 2022/` (4 `code_base*.py`
  scripts of the August 2022 exam example).
- Scripts were copied into a private work folder (never into the library) and run with
  python 3.12, **CoolProp 8.0.0** (pip CoolProp, scipy, numpy, matplotlib), `MPLBACKEND=Agg`,
  60 s timeout, stdin closed. Spyder-style `get_ipython().magic('reset -f')` calls were
  stubbed (no physics touched). One script execs a companion under a stale file name
  (`ThAp20_R06E02_function.py`, present as `ThAp21_...`): the companion was provided under
  the expected name instead of editing the script. 80 of 82 run.
- Each script was mapped to a library model by exercise (series/exercise number, statement
  data, printed values), helped by `sources/thermo_models/inventory.csv` (EES file →
  library_id) and the model `.sol` files. Folder numbering of 2022-2023 is shifted by one
  against the legacy file names (`R4/old Python/ThAp21_R03E0*.py`, `R7/old/ThAp21_R06E0*.py`,
  `R8.../ThAp21_R07E0*.py`, `R9/Python/ThAp21_R08E0*.py`, `R11/Python/ThAp21_R9E0*.py`).
- Privacy: `Aout 2022/code_base Q_COP <student>.py` is referred to as "Aout 2022/exam
  script COP"; credit *Thermodynamics Laboratory, University of Liège*. The
  `2022-2023/Etudiants moniteurs/` zips (student monitor submissions) were **not** used.
  No student names appear in `C-500.csv`, this report or this repository.

## `differs` diagnoses (6)

1. **R02E04** (turbine, 657.48 kW) — statement numbers of this first-law variant are not in
   the library (nearest family CSL-0053); same conclusion as C-501's R02E05.
2. **R04E01 Otto** vs CSL-0049 — statement data (rv 9, q 2600 kJ/kg, constant-gamma
   shortcut) vs the 2022 import (rv 8, q 800 kJ/kg, variable cv); C-501 same diagnosis.
3. **R04E02 Diesel** vs CSL-0280 — other rv/heat input; the 2021 statement adds engine
   power and torque.
4. **R06E02 Rankine with extraction** vs CSL-0029 — extraction at 14 bar, condenser 0.2 bar
   vs the imported 25 bar/0.1 bar exercise (cooling water 2975 vs 2813 kg/s, extraction
   20.76 % vs 25.9 %); same physics, C-501 same conclusion (R07E02).
5. **R9E01 adiabatic flame T** vs CSL-0046 — same statement, stoichiometry identical to
   1e-5 (far 1.66 %, far_st 6.65 %); the model's 961.7 K matches the textbook value for
   octane with 400 % theoretical air (≈ 962 K), the script's 913 K is 48 K low: CoolProp
   HEOS sensible enthalpies (own reference zero) mixed with JANAF formation enthalpies —
   a script-side reference error, no model change.
6. **R9E02 gasoline exhaust analysis** vs CSL-0266 — same inputs, the unburned-CO loss is
   identical (8.52 kW); the useful power (−74.7 vs −83.9 kW) differs through the exhaust
   enthalpy terms, same CoolProp-vs-EES-NASA reference mismatch as R9E01; model verified
   against its EES stored solution (54/54).
