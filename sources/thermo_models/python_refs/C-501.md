# C-501 — T-VERIFY: independent Python references of the course *Thermodynamique appliquée* (batch B-21, 2026-11-03)

## Method

- Source root (read-only): `~/Nextcloud/thermo_models/thermodynamique appliquee/` — folders `2017-2018/`,
  `2018-2019/`, `Exam passés/` and `Exam janv 2021/` (96 Python scripts, teacher solutions author "BJD"
  = Stéphane Bertagnolio, plus compact exam solutions "BD").
- Scripts were copied into a private work folder (never into the library), run with python 3.12,
  **CoolProp 8.0.0** (pip CoolProp 8.0.0, scipy, numpy, matplotlib; `IPython` added for 11 Spyder-style
  scripts whose `get_ipython().magic('reset -f')` call was stubbed — physics untouched), `MPLBACKEND=Agg`,
  60 s timeout. Nothing was written into the source root.
- Each script was mapped to a library model by exercise (series/exercise number, statement and given
  numbers), helped by `sources/thermo_models/inventory.csv` (EES file → library_id) and the model READMEs;
  the `.sol` of the matching model (or of the variant, e.g. CSL-0058 `_coolsolve`) was used for comparison.
- Privacy: 6 scripts that carry a first name in their file name were ran from generic names and are
  referred to as "exam script 1…6"; their authorship credit is *Thermodynamics Laboratory, University of
  Liège*. No student names appear in `C-501.csv`, this report or this repository.
